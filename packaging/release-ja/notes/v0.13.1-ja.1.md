## このリリースの内容 / What's new

本家 DeckCraft 0.13.1 までの更新を取り込んだ DeckCraft-ja です(前回 v0.10.0-ja.1 は本家 0.10.0 相当)。

### 本家から取り込んだ主な更新(0.11.0〜0.13.1)

- egui 0.37 への移行(画面描画・入力まわりの基盤更新)
- 書式設定ウィンドウ: 影・光彩・ぼかしのプリセット、図形の拡大縮小と基準位置、パターン塗りつぶしのギャラリー、スライドの背景で塗りつぶし
- 段組みダイアログ、「プレゼンテーション全体」の校正言語、アウトラインの RTF 保存と読み込み
- 頂点の編集の強化、表のセル範囲の選択、グラフの文字色
- スライドの再利用で挿入するスライドを選べるように
- クイック アクセス ツール バーの Alt+1〜9、スライド ショーで戻るときの画面切り替えの逆再生、発表者ビューの次のスライドを裏で描画
- 大文字だけの単語のスペル候補、PowerPoint ファイルの保存時の再現性の向上(グラデーションの反転、箇条書き、線の設定など)
- ファイル読み込み・クリップボード・動画・フォントまわりの堅牢化

### DeckCraft-ja 独自の更新

- macOS の日本語入力(再変換・変換中の文字列の扱い)の対応を、本家が採用した新しい winit の上に移植
- 本家で増えた画面の文言をすべて日本語化(パターン名、段組み、更新の確認、印刷やアクセシビリティの名前など)
- 単位(インチ/センチ)と言語設定を本家の新機能と統合: 単位は「環境設定」で選んだものを優先し、未設定なら地域の単位
- 数式: エージェント(CLI/MCP)から数式を一覧・書き換えできるように
- アップデートの確認先をこのリポジトリに変更(日本語対応のない本家版を案内しない)

### Highlights

DeckCraft-ja synced with upstream DeckCraft 0.13.1 (from 0.10.0): egui 0.37, Format pane effects and
scaling, Columns, whole-presentation proofing language, RTF outlines, Edit Points, Reuse Slides
picker, QAT Alt+1..9, and many robustness fixes. Fork-specific: macOS Japanese input
(reconversion) ported onto the new winit, Japanese for every new interface string, units and
language settings unified with upstream's, equations for agents, and update checks pointed at
this repository.
